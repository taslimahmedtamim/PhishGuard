# PhishGuard - Real-time Phishing Detection System

PhishGuard is an end-to-end local phishing detection system built for research and demonstration purposes. It consists of a machine learning backend and a Manifest V3 Chrome Extension.

## Project Architecture

1. **Chrome Extension**: Monitors browsing activity and requests predictions for new URLs. Detects privacy-sensitive fields.
2. **Flask API Backend**: Exposes endpoints (`/predict`, `/health`) to receive URLs.
3. **Feature Extractor**: Performs real-time WHOIS, SSL, and HTTP requests to extract features matching the trained model's requirements.
4. **Machine Learning Model**: Uses the trained model (`combined_model.pkl`) to infer whether a URL is Legitimate or Phishing.

## Repository Structure

- `Datasets/`: Contains the evaluation/training dataset (`dataset.csv`).
- `Framework/`: Contains the original model training and feature extraction logic (`main.py`) and the trained `.pkl` models.
- `backend/`: Contains the Flask API (`app.py`), feature service, and model service.
- `extension/`: Contains the Chrome Extension files (Manifest V3).
- `docs/`: Architecture diagrams.
- `tests/`: Automated test scripts.
- `training/`: Contains scripts for training and evaluating the 1.56 million URL dataset (`train_model.py`, `evaluate_model.py`).
- `results/`: Contains evaluation metrics, feature importances, and confusion matrices.
- `models/`: Contains the compiled `.pkl` models generated by the training pipeline.

## Dataset and Training Upgrade

This repository has been upgraded to support the 1.56 million URL dataset (`vonDataset20180426.dill`).

### 1. Dataset Installation
To run the training script yourself, you must first download the massive 1.56 million URL dataset, as it is too large to host on GitHub. 

**[Download vonDataset20180426.dill from Google Drive here](https://drive.google.com/drive/folders/1E0I36is_IpHWNDgW9SEU64v3RPLiCRqz?usp=drive_link)**

Once downloaded, ensure `vonDataset20180426.dill` is placed inside the `Datasets/` directory. 

### 2. Inspect Dataset Shapes
You can inspect the `.dill` arrays by running any custom inspection scripts locally, but the provided training script will automatically decode the `train_x` and `test_x` character mappings.

### 3. Model Training
Run the training script to decode 1.25 million training URLs, perform Lexical Feature Extraction, and save the updated Random Forest and XGBoost models:
```bash
python training/train_model.py
```

### 4. Evaluation
Evaluate the models on the 155k test set and generate graphs in `results/`:
```bash
python training/evaluate_model.py
```

## Setup Instructions

### 1. Start the Flask Backend

Open a terminal or PowerShell, navigate to the `backend` directory, and install the dependencies:

```bash
cd backend
python -m venv venv
```

Activate the virtual environment:
- **Windows**: `venv\Scripts\activate`
- **macOS/Linux**: `source venv/bin/activate`

Install requirements and start the API:
```bash
pip install -r requirements.txt
python app.py
```

*The API will start on `http://127.0.0.1:5000`.*

### 2. Verify the API is Running
Open a browser and navigate to:
[http://127.0.0.1:5000/health](http://127.0.0.1:5000/health)

You should see:
```json
{"model_loaded": true, "services_initialized": true, "status": "ok"}
```

### 3. Load the Chrome Extension
1. Open Google Chrome.
2. Navigate to `chrome://extensions/`.
3. Enable **Developer mode** in the top right corner.
4. Click **Load unpacked** in the top left corner.
5. Select the `extension` folder located inside the PhishGuard project directory.

## Demonstration Workflow

1. Pin the PhishGuard extension to your browser toolbar.
2. Visit a safe website (e.g., [https://google.com](https://google.com)).
3. Click the PhishGuard icon. The extension will display **SAFE** along with a confidence percentage.
4. To test a phishing detection, use one of the safe demonstration URLs from the original dataset if available, or simulate a request via API. 
*(Note: Do not visit real phishing URLs on your personal machine unless you understand the risks).*

### Manual API Testing
You can manually test the API using PowerShell:
```powershell
Invoke-RestMethod -Uri "http://127.0.0.1:5000/predict" -Method Post -ContentType "application/json" -Body '{"url":"https://example.com"}'
```

## Troubleshooting
- **API Fails to Start**: Ensure the `phishguard_models/` folder contains the `.pkl` files. Run `verify_model.py` in the root directory to assert compatibility.
- **Model Discrepancy**: The original research mentions Random Forest, but the provided training script saves the XGBoost model. This project currently uses XGBoost to ensure pipeline compatibility. See `REPORT.md` for details.
